SONYEDGE · 重构版设计文档 v1.0
安静的专业摄影导入工具 — 落地规格
基准画布 360×792 dp · Kotlin + Jetpack Compose (Material 3 定制主题) · 浅色默认,深色为夜间模式 · 大图预览恒为沉浸黑。设计主张:照片是屏幕上最亮的内容;一种琥珀强调色只用于主操作与选中;文件名、SSID、计数、速度等"机器信息"一律等宽字体;大号日期数字构成时间线的视觉锚点。所有页面实例均可交互,可直接走完整流程核对行为。
功能对照基线:仓库 docs/design/figma-ui-redesign/phase-0-discovery.md 的功能保留矩阵;实机基线 ILCE-7RM3。本文档只重构信息架构/视觉/交互,不改协议与下载栈。

字体
UI 正文 — Noto Sans SC(Compose 默认中文回退即可) 数字展示 — Space Grotesk 700:日期大数字 30sp、进度百分比 26sp、机型名 16–27sp 机器信息 — IBM Plex Mono(或 JetBrains Mono):文件名 11–12.5sp、SSID、计数、速度/ETA/字节、路径、版本号 层级:页标题 19sp/700 · 栏标题 16.5sp/600 · 列表主文本 14.5sp/500–600 · 辅助 12–12.5sp · 分组眉题 11sp/600 + 0.12em 字距 最小可读字号 11sp;所有按钮文字单行完整显示(白名单已核对最长“扫描相机二维码”7 字)
间距 · 圆角 · 高度
页面水平边距 20dp(卡片列表 16dp);卡片内边距 14–16dp 圆角:卡片/按钮 8dp · 输入框/次级按钮 6dp · 悬浮多选条 12dp · 缩略图胶片条 5dp 高度:主按钮 44–48dp · 次级按钮 38–40dp · 小按钮 34dp · 顶栏 54dp · 底部导航 72dp(含 16dp 手势内边距) 网格:3 列 · 2dp 间距 · 1:1 · 全出血(0 水平边距);触控目标 ≥44dp 状态栏占位 30dp;内容滚动区底部预留 94dp(多选时 126dp)
01 · 连接流程
连接成功后直接落在「拍摄日期时间线」,不设中转首页(对应 autoNextDateFolder 停在 Date 层的既有行为)。手动输入 Wi-Fi 仅在失败后出现;帮助入口是弹窗而非新页面。
1A · 未连接 — 设备票据卡
机型 Space Grotesk 24sp;SSID mono 11.5sp。主 CTA「一键连接」仅在有已保存相机时为实心;否则「扫描二维码」升级为主 CTA。
1B · 正在连接 — 垂直步骤时间线
三步:连接相机 Wi-Fi → 验证相机 → 准备照片;左侧 2dp 竖轨连接节点。进行中=琥珀旋转环(900ms/圈),完成=teal 对勾,失败=rose error。底部常驻「取消连接」与“通常需要 5–10 秒”预期管理文案。
1C · 连接失败 → 重试 / 手动 Wi-Fi
失败卡说明面向用户(“相机屏幕停留在发送到智能手机”),不出现 IP/SSDP/DMS 术语。点击「手动输入 Wi-Fi」内联展开表单。
1D · 日期时间线(连接后落点)
顶部状态条:teal 呼吸点 + 机型 + 刷新 + 断开(带确认弹窗)。每行 = 大日期数字 + 三格胶片条(首图宽) + mono 计数;空目录行降透明度 55% 并显示虚线占位。
1E · 正在接收相机选择
相机主动推送(XPush)时在时间线顶部插入 teal 横幅,「查看」跳转传输页;设置中的“接收相机选择”开关控制该能力。
02 · 浏览、多选与大图预览
网格全出血、缩略图 1:1 稳定比例、不显示文件名;长按进入多选(保留 itemKey 稳定键与 32 条分页)。多选操作收进悬浮工具条,不遮挡最后一行(滚动区底部预留 126dp)。
2A · 照片网格(37 张)
顶栏:返回 + 日期 + mono 计数 + 多选按钮;首次进入显示可关闭的“长按多选”提示条。加载态为 12 格脉冲骨架;500 张目录用相同布局 + lazy 加载(实例里选 7月12日 可实测滚动)。
2B · 多选模式 — 悬浮工具条
顶栏变为 关闭 + “已选 n 张”(n 琥珀色) + 全选/反选;底部悬浮条(12dp 圆角、模糊底) = 清除 + 实心「导入 n 张」。选中图:3dp 琥珀描边 + 左上琥珀对勾 + 缩至 0.85;未选图降透明度 75%。0 张时导入按钮禁用灰。
2C · 空目录
2D · 读取超时 + 重试
2E · 大图预览(恒黑)
文件名与“12 / 37”计数用 mono;单击切换控件显隐,双击 2.2× 缩放,左右滑动翻页(阈值 45dp)。预览加载预览尺寸图,导入时才取原图并校验(保留 ProgressiveCameraImage / 邻图预取 / EXIF 方向)。控件区底部含手势安全边距 26dp。
03 · 传输(五种状态)
任务卡以大号百分比数字为主角,mono 三行:当前文件 / 速度·剩余时间 / 张数·字节 — 与 onDownloadProgress 现有指标一一对应。页眉常驻保存路径 DCIM/Sony Picture 与「打开相册」。

04 · 设置 与 深色模式
诊断日志折叠于「高级设置」,普通用户全程看不到协议术语。深色为完整夜间模式(跟随系统或手动),仅令牌切换、布局零改动;大图预览两种主题下都是纯黑。

导航与跳转
底部导航 3 项:浏览 / 传输 / 设置(大图预览与多选时隐藏) 浏览 Tab 内部层级:未连接 → 连接中 → 日期时间线 → 照片网格(无独立首页) 导入动作(多选/预览单张) → 创建任务 + Snackbar「已加入传输队列 · 查看」 相机推送 → 时间线顶部 teal 横幅 → 查看 → 传输页 断开 / 忘记相机 → 二次确认弹窗(危险动作 rose 文字) Snackbar 固定于底栏上方 14dp,3.2s 自动消失
系统返回键优先级(与现有实现一致)
1. 关闭大图预览(回网格,保留滚动位置——网格常驻于预览层下方) 2. 退出多选并清空选择 3. 照片网格 → 日期时间线 4. 正在连接 → 取消连接回未连接 5. 弹窗/输入框 → 仅关闭自身 6. 传输/设置 Tab → 回浏览 Tab → 退出应用 下载通知点击 → 回传输页(保留现有 PendingIntent 目标)
动效规格
主导航切换:180ms fade-through 进出网格层级:240ms 共享轴水平位移(本原型为 fade 简化) 预览开合:220ms 淡入 + 图像 0.96→1.0;工具栏 220ms 反向滑入/出 工具栏显隐:单击图片,180ms alpha + 位移 双击缩放:250ms 至 2.2×(落地保留现有 1×–5× 捏合与边界平移) 选中缩略图:150ms 缩放 0.85 + 描边;悬浮多选条 180ms 上滑入 进度条:width 400ms 插值;完成态图标 scale/fade 减少动效系统设置:去位移,仅保留短交叉淡化
响应式(> 360dp)
< 600dp:底部导航;网格 Adaptive(minSize 108dp)≈3 列 600–839dp:改用 NavigationRail;网格 minSize 132dp;内容列限宽 560dp 居中 ≥ 840dp:Rail + 可选双栏(左时间线 / 右网格);网格 minSize 148dp 全部容器用 WindowInsets + contentPadding,不写死屏高;大字号下操作行换行不裁切
